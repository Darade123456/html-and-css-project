## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/Darade123456/html-and-css-project.git
   cd technotes-hub
   ```

2. Open `index.html` in your web browser

3. To deploy, use any web hosting service:
   - GitHub Pages
   - Netlify
   - Vercel
   - Traditional web hosts

## AdSense Setup

1. Update the AdSense code in `index.html`:
   ```html
   <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-YOUR_CODE_HERE"></script>
   ```

2. Add ad units to your content pages for better revenue
